# evalcheck rules

Generated by `python3 tools/evalcheck.py --catalog`. Do not edit by hand.

A-codes are prose checks; their patterns are in `tools/evalcheck/catalogs.py`
and their classes in [the prose references](prose/README.md). E-codes check the
evaluation itself and quote [the platform instructions](evaluation-instructions.md).

Scope `authored` is text we type into the platform, where a finding is an ERROR.
Scope `evidence` is a harness output, which we cannot edit, so a finding is a
NOTE to weigh under Format & Presentation. `both` runs over each at its own level.
