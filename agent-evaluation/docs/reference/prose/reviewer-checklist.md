# Reviewer Checklist: Signs of LLM Use

> Transcription of the reviewer-side "signs of LLM use" checklist. It is the short list a
> reviewer scans a submission against before the severity table in `style-guide-llm-tells.md`
> is applied. The mapping of each line to a coded check or a manual read is in
> `llm-prose-tells.md`, class 12.

---

- Watch for any signs of LLM use in submissions.
- Check any solutions, instructions, reports, or notes that appear generated.
- LLM use will typically look like:
  - Repeated em dashes - Frequent use of —
  - Long instruction.md files — Unusually lengthy instructions, especially with repeated or overexplained details.
  - "It's not just X, it's Y" phrasing - Explaining something by first saying what it is not, then what it is.
  - Negative parallelism - Repeated contrast structures using "not," "not only," or similar wording.
  - Long, highly uniform bullet lists - Many bullets with similar length, grammar, and formatting.
  - Highly polished grammar - Consistently correct punctuation, sentence structure, using the oxford comma.
  - Sycophantic language - Overly agreeable, validating, or enthusiastic wording.
  - Avoiding simple verbs - Replacing "is," "are," or "has" with phrases like "serves as," "stands as," "boasts," "features," "offers," or "represents."
  - Rule-of-three phrasing - Repeatedly grouping ideas into sets of three (lists)
  - Excessive lexical variation - Using several different phrases for the same concept instead of repeating one clear term.
  - Polished parallel structures - Repeating the same grammatical pattern across sentences or list items.
  - Contrast-based sentences - Repeatedly setting one idea against another to make a point.
  - Unusually consistent sentence style - Similar sentence-by-sentence length and structure throughout.
