Going forwards, when requesting investment from IDM, please submit a request with the following information, in the following order and please do not include anything else:

Your business name

The business name of the business you’re looking to acquire [Target company]

The target company’s address

The target company’s company number

The target company’s owner’s name

The EBITDA of the target company (split by site if applicable as well as total)

The multiplier or multipliers used

Your overall valuation

Description of how you arrived at that valuation from the figures provided eg. Any adjustments made either in our favour or the seller’s favour.

Remember, we want to be seen as presenting fair offers from the start of the purchasing process.  It’s ok to give a valuation range if there are some issues with the figures from the seller that are yet to be confirmed.

If you have any questions, please let me know.
