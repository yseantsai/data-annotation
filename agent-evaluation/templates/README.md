# Templates

- [prompt.md](prompt.md): the prompt record, filled verbatim before any run
- [ratings.md](ratings.md): the per-harness ratings table and preference line
- [collect-assets-prompt.md](collect-assets-prompt.md): paste into another assistant that has platform and disk access, to fetch and file one task's assets
